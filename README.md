# Student CRUD Operations

This is a simple Student CRUD API project using **FastAPI and PostgreSQL**.

I created this project to learn how APIs work and how to connect FastAPI with a PostgreSQL database.

## Technologies Used

* Python
* FastAPI
* PostgreSQL
* SQLAlchemy
* Pydantic
* JWT Authentication
* Uvicorn

## Project Files

### main.py

This file contains the FastAPI routes and API endpoints.

### database.py

This file is used to connect FastAPI with PostgreSQL.

### models.py

This file contains the database tables like Student and User.

### schemas.py

This file is used to define the request data format.

### operations.py

This file contains the database CRUD operations.

### authentication.py

This file contains password hashing and JWT token authentication.

## Student CRUD Operations

I created APIs for:

* Add student
* Get all students
* Get student by ID
* Update student
* Delete student
* Get students using limit

Example:

GET /students
GET /student/1
GET /students?limit=2
POST /add_student
PATCH /update/1
DELETE /delete/1

## Authentication

I also added simple JWT authentication.

The flow is:

Register
   ↓
Login
   ↓
Get JWT Token
   ↓
Bearer Token
   ↓
Access Student APIs

For login, I use username and password.

After successful login, the API gives an access token.

The token is used as:

Authorization: Bearer <token>

Protected APIs cannot be accessed without a valid token.

## PostgreSQL

Student data is stored in PostgreSQL.

The student ID is automatically generated by the database.

## Run the Project

First install the required packages:
pip install -r requirements.txt

Then run:
uvicorn main:app --reload

Open Swagger:
http://127.0.0.1:8000/docs
